# ATS Keyword Matrix
Most Swedish/EU companies filter CVs with an ATS before a human reads them. Make sure the
**exact words** from the job description appear in your CV — *only if true*. Below are the
keyword clusters to mirror per family. Don't keyword-stuff; weave them into Skills + bullets.

---
