## RustIO — the framework I authored

**rustio-admin** — a Postgres-first admin framework for Rust ("Django Admin for Rust"). Authentication, sessions, recovery, role-based access, MFA, and a complete audit trail are designed as **one system**, not bolted on. An admin surface is one derive, one impl, one register call.
*12-crate Rust workspace · single binary · no build step · no frontend pipeline.*

**rustio** — the web framework: plain Rust structs become a working admin UI, database, auth, and HTTP server, with a guided CLI that turns a one-sentence brief into a reviewed schema.
*6-crate Rust workspace.*
